# TTM Calendar — ตัวติดตั้ง

ตัวติดตั้งโปรแกรม TTM Calendar (โปรแกรมนัดหมายนวดแผนไทย ติดตั้งในเครื่อง) สำหรับ Windows และ macOS

- ดาวน์โหลดรุ่นล่าสุด: [Releases](https://github.com/piyawatandben2-cell/ttm-calendar-releases/releases/latest)
- ทดลองใช้ สั่งซื้อ และรับคีย์ใบอนุญาต: https://ttm-calendar.netlify.app

โปรแกรมต้องใช้คีย์ใบอนุญาตที่ออกให้เฉพาะเครื่องจึงจะเปิดใช้งานได้
